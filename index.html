E-KMS 浏览器扩展隐私政策

更新日期：2026 年 9 月 24 日

本政策适用于 Microsoft Edge 中的 E-KMS 浏览器扩展及其连接的公司 E-KMS 服务。E-KMS 帮助获授权员工查找、使用、保存与更新企业账号，使用前需要公司身份认证。当前服务不开放个人密码库。

运营主体：泛微网络科技股份有限公司。本政策说明我们处理哪些信息、处理目的、保存方式，以及您可以采取的控制措施。

1. 公司登录与身份信息

登录时，扩展处理您输入的 OA 账号、密码，以及必要时的图形验证码。登录信息经过请求体加密与 HTTPS 传输，由 E-KMS Server 在本次登录所需的内存中解密并向公司 OA 验证。E-KMS 不保存您的 OA 密码，也不将其写入日志或审计。

认证成功后，服务保存与授权管理有关的员工标识、姓名、部门、分部及在职状态等身份和组织信息，并按需刷新。扩展接收用于展示和访问控制的用户资料与短期会话令牌，不读取用户邮箱或岗位资料。

2. 企业账号与网页匹配

  • 企业凭据：扩展从公司 Server 获取您有权使用的账号信息，并在查看、复制、动态验证码读取或填充时按次请求相关秘密。Server 实时检查权限和有效期；企业凭据在 Server 加密保存。
  • 网页地址：登录期间，为显示匹配数量、查找账号和提供网页提示，扩展读取相关标签页地址，并向公司 Server 发送规范化后的协议、主机、端口和路径。查询参数及片段不会随匹配请求发送，包含 URL 用户信息的地址会被拒绝。扩展不读取浏览器历史记录数据库，也不建立用于广告或用户画像的浏览档案。
  • 登录表单：在您授予网站权限、启用相关提示或主动使用填充功能时，扩展通过随安装包提供的脚本识别登录字段，并处理完成登录或保存提示所需的表单内容。不会采集与这些功能无关的网页正文、邮件或聊天内容。
  • 填充与剪贴板：您选择填充时，凭据会被写入匹配网站的登录表单；满足条件时会触发表单提交。您选择复制时，相应内容会进入操作系统剪贴板。目标网站对提交信息的处理遵循其自身规则，请仅在可信的网站和设备上操作。

3. 登录后保存与密码变化比较

开启“登录后提示保存企业账密”并授予网站权限后，扩展仅在与您可见的公司系统相匹配的网站上观察可识别的登录表单提交。用户名和密码临时保留在扩展后台内存，最长两分钟；跨网站跳转、关闭标签页、退出、关闭功能或到期会清除待保存内容。

已有账号的密码比较：如果匹配到唯一且您可编辑的已有企业账号，扩展会在弹出更新提示前，通过 HTTPS 将本次输入的用户名、密码及账号版本发送给公司 Server。Server 在内存中比较密码是否变化，仅返回变化状态和版本，不返回原密码，也不在比较时修改已保存凭据。

新账号的待保存账密在您确认保存前不会上传到 Server。新增保存和已有凭据更新均需您明确确认，并由 Server 再次校验权限。保存提示不代表目标网站已确认登录成功。

4. 本机存储与安全审计

  • 持久设置：扩展在本机保存服务地址、记住的登录账号标识、提示偏好，以及您选择不再提示的网站 Origin。这些设置不包含密码。
  • 浏览器会话：公司会话令牌、当前用户资料及是否需要验证码的标记保存在浏览器会话存储中；退出时清除公司会话。密码、动态验证码、待保存表单密码不会写入扩展持久存储。
  • 安全记录：Server 为认证保护、授权追溯及企业安全审计处理来源 IP、相关用户或对象标识、操作类型、时间及结果等信息。秘密读取和修改按次审计；日志和审计不记录密码、验证码或会话令牌。IP 用于安全目的，不用于 GPS 定位。
  • 版本查询：扩展会向同一公司 Server 请求公开版本清单，用于显示更新信息，不下载执行远程代码。

5. 信息接收方与使用限制

信息仅用于公司身份认证、企业账号授权与使用、网页匹配、凭据维护和安全审计。接收方包括公司 E-KMS 服务、执行身份验证的公司 OA 服务，以及您选择提交登录表单的目标网站。企业账号信息按服务端业务权限向责任人和获授权使用人提供；具备审计权限的人员可访问相应的非秘密审计记录，全局管理员身份本身不授予企业密码读取权。

E-KMS 不出售用户数据，不将数据用于广告投放、与企业账号功能无关的分析或信用评估，不内置第三方广告或行为分析 SDK。浏览器商店自身的安装与更新服务由其提供方按相应政策处理。

6. 保存期限与删除

OA 密码仅用于当次验证；待保存表单内容按上文的短期内存规则清除。会话受过期、退出及服务端撤销限制。本机偏好保留至修改、清除扩展数据或卸载扩展。

服务端身份、企业账号和业务审计记录用于持续授权管理与安全追溯；当前系统不会因关闭或卸载扩展而自动删除这些记录。停止使用、账号归档及授权撤销也不等于删除全部历史记录。有关服务端信息的查阅、更正、保存期限或删除需求，请通过下述联系方式提出，由运营方结合业务责任、审计需要和适用要求处理；我们不承诺卸载即清空服务端数据。

7. 您的选择

您可以在扩展偏好中关闭网页登录提示或保存提示，设置及恢复不再提示的网站，在 Microsoft Edge 扩展管理页撤销网站访问权限、禁用或卸载扩展，也可以退出公司登录。关闭保存提示会停止该功能后续的表单采集和密码比较，但不影响您主动发起的账号查看或复制等操作。停止扩展全部活动可禁用或卸载扩展。

需要查阅、更正与您有关的信息、申请删除或反映隐私问题时，请联系运营方。企业共享账号属于公司业务资料，相关处理还需核验您的身份、权限及公司业务责任；请勿在反馈中发送 OA 密码、企业密码或验证码。

8. 政策更新与联系

功能或信息处理方式调整时，我们会更新本页面并注明更新日期；需要额外授权的功能会按适用要求提示并请求授权。
